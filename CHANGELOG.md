# Changelog

## 0.6.0-beta.1

- Consolidates the previously local short-lesson, English I vocabulary prioritization, structured sense/phrase, independent recall, adaptive time budget, and learner analytics work into the actual application.
- Adds optional Word FC: daily matches, 3/1/0 points, division progression, tactics, kits, recovery milestones, season reports, and evidence-based vocabulary roster. Academy scouting uses the existing personal new-word order; recovery practice reuses due weak tasks.
- Separates feature styles; builds the standalone preview from the production application rather than publishing an unrelated 36-word demo.
- Preserves existing word keys and schema-3 backup format; immediate correction cannot overwrite the original legacy lapse.
- Beta limitations: 36 structured focus entries and 41 independent use units are a pilot; word-level exam statistics are not per-sense statistics. Full device persistence, signed Android distribution, accessibility audit and empirical learning-effect validation remain release gates.
