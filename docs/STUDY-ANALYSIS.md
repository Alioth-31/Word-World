# 学习记录与分析统计口径

- 累计已学：有基础词汇学习记录的唯一词条数；自认熟悉单独统计。不是掌握量。
- 待复习：基础词及独立用法、拼写记忆记录当前到期数量。上次未想起：基础词最近一次评分为 again 的数量。
- 新学与单词复习：日记录 new 及 max(0,reviews-new)，避免首次学习重复计为复习。用法次数由实际作答证据汇总，包括拼写等专项练习。日数据按本地日期分组。7/30 天前期比较为不重叠窗口内的实际活动量，不等同于学习效果改善。没有前期活动则不显示比较。
- 记忆保持：近 30 日每个知识单位最近一次间隔至少 24h 的无提示回忆，单词自评 again 为失败、hard/good/easy 为成功；重点用法采用独立客观正确性记录（不含拼写）。每类少于 5 个样本不展示百分比，阈值为界面初始规则而非统计有效性的证明。重复题表现不代表迁移。组内即时修复不计入延迟回忆。
- 核心词覆盖：原有 P0 分级中有学习记录的词。多年复现词：英语一语料统计中至少五个年份检出的词，为产品筛选口径，非义项考频。熟词僻义覆盖只统计现有练习库中有熟词僻义教学标注的 context 单位，不代表全部考研熟词僻义。不同类别可能重叠，不相加。
- 建议：当前到期任务优先；逾期一天以上单独提示；若无到期任务但有基础词或重点用法最近失败，可查阅相关词条；否则继续正常计划。不会为记录页重置 FSRS 或重复创建复习记录。
- 证据滚动保留上限为 5,000 条，长期历史和旧版备份可能缺乏用法事件；不伪造缺失数据，也不估算考试分数。日统计累计值与滚动事件口径并不完全相同。

0.6.0-beta.1 的浏览器预览直接使用完整应用及 5,530 词词库，采用简化调度器；Android 构建使用 ts-fsrs。浏览器截图合成记录仅在测试脚本中注入，用户打开 HTML 后从自身记录开始。

## 薄弱项与趋势

薄弱词按唯一词条聚合，基础词遗忘及重点用法错误分别标记，是否到期来自现有调度记录；优先列出到期项，再按原重要性排名排序。每次展开 8 条，保留全部待巩固词可查询，不将词义和用法错误相加为词数。图表采用从零开始的等间隔刻度，7/30 天范围仅影响趋势，概览始终显示近七日摘要。各页面共用同一份统计数据。

## 延迟回忆与复习排程

实际间隔由复习前 lastReviewed 与当前时间差获得，只有≥24h的事件保留 gapMs。历史缺失的字段不回填。间隔分组显示最近30日每词最近一次有明确间隔的无提示复测，按真实间隔分组，不是同一批词的纵向遗忘曲线。反复困难要求同一当前失败的知识单位在不同日期至少两次延迟失败。已修复的项目不列为当前薄弱；同一词多个义项分别判断。专项入口仅选已到期的失败记录，优先反复困难及考研重要性，最多8项；不计入新学额度，不覆盖未到期任务。未来排程仅统计现有 due 字段，按本地日历日期归类，不是对未来学习负担的预测。

## 页面组织与联动

学习记录采用概览、学习趋势、记忆与巩固三个页内分类。概览显示已学、到期、近期活动与核心词覆盖；趋势提供 7/30 日窗口；记忆与巩固聚合延迟证据、薄弱任务及未来到期排程。Word FC 俱乐部读取相同的分析快照；回归训练使用同一个已到期薄弱任务入口。赛事积分不进入学习效果指标。
