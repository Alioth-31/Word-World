## 词库构建

仓库已内置 **5,530 条真实考研词条**，分别保存英文词、来源释义、英式音标、原始词频与两种排名，并引用 **3,050 词核心集合**辅助计算重要性。原始数据来自下方开源项目；完整词表按 **CC BY-NC-SA 4.0** 发布，不适用本仓库代码的 MIT 许可证（[完整许可文本](../app/data/LICENSE-CC-BY-NC-SA-4.0.txt)）。

原始词表附带的第三方真题、新闻及其他例句未随仓库打包；少量自编示例句作为学习辅助。构建脚本可以重新获取来源数据，并在可用时加入 2010—2025 年英语（一）正文词形计数。

```bash
npm install
npm run data
# 无法获取真题语料时
node scripts/prepare-data.cjs --without-corpus
# 已将来源文件放入 sources/ 时
node scripts/prepare-data.cjs --offline
```

`sources/` 已被 Git 忽略。`app/data/vocabulary.js` **已经包含第三方授权的真实词表**，不得以本项目 MIT 许可证重新分发。更新脚本会替换此文件；重要性结果可能随来源和语料覆盖改变。常规 `npm run build` 不再联网更新词库，仅校验已提交数据并构建复习调度器；需要更新词库时明确执行 `npm run build:refresh-data`，核查差异后提交。

**排序含义**：来源词频是上游混合英语考试试卷中的出现次数，不是英语一专属频率；综合重要性则将来源真题次数、混合词频、CEFR 和核心词表作为启发式学习权重，独立于来源词频排名。词汇优先级属于**未经考试表现验证的启发式评分**。表面词形匹配不等于词元匹配，也不能确定多义词在真题中的实际义项。语料不足时退回来源词表字段，不能称作独立核实的英语（一）词频。

## 排序版本 2

本次内置词库依据 NETEMVocabulary 完整表与核心表（[上游字段说明](https://github.com/exam-data/NETEMVocabulary/blob/master/docs/data-dictionary.md)）更新，保留原始词频和原始释义。当前内置数据的真题次数均有数值：2,443 个为正数，3,087 个为 0；CEFR 未匹配 1,159 个。零值只表示来源词表统计值为零，不代表该词从未出现在英语一试卷中。

未引入独立英语一正文语料时，综合重要性由以下指标构成：

| 指标 | 权重 |
|---|---:|
| 来源真题次数（2005—2023 年考研真题词表） | 56% |
| 来源混合考试词频 | 26% |
| 3,050 词核心表成员 | 10% |
| CEFR 难度 | 6% |
| 学术词汇标记 | 2% |

计数项以全表最大值进行对数归一化。缺失真题次数保留为 null，评分贡献为零，不重新分配权重；未知 CEFR 采用中性值 0.5。该权重是可解释的学习启发式，不是根据考试成绩拟合的预测模型。两种排序独立；词频相同按单词字母顺序排列。分层为重要性排名的 20% / 30% / 30% / 20%，不表示官方考试难度。

如果另行导入至少 12 个有效年份的英语一正文，评分采用正文表面词形次数 30%、年份覆盖 15%、来源真题次数 30%、混合词频 12%、核心表 8%、CEFR 4%、学术词汇 1%。当前内置词库没有使用这组正文统计。

[补充义项](../data/sense-notes.json) 是项目原创中文学习提示，参考 Cambridge Dictionary 的对应词条编写；不复制其英文释义或例句，不宣称是真题义项频率。原始释义仍保留，更新脚本会重新合并补充义项。

## 英语一专属词频（独立统计）

`data/exam1-frequency.json` 保存 5,530 个词条在 2010—2025 年英语一统一正文范围内的统计：完形填空可见文字、阅读理解 A 的四篇正文、翻译原文；不包含新题型、题干、选项、解析、作文和完形未填入的答案。固定来源版本及 16 份试卷 Git blob 校验值见 [exam1-source.json](../data/exam1-source.json)。

统计区分大小写归一后的直接词形匹配与唯一候选规则推断（大小写有独立词条时按原拼写匹配）。词组在同一段内匹配，允许与组成词的计数重叠。规则推断仅处理词库中未直接命中的词形，存在歧义时不归并；不等同于经过词性和义项消歧的词元统计。两个排名均按正数频次降序、相同次数并列，未观察到的词排名为 null，逐年计数存为 [直接匹配次数, 推断次数]。

当前结果包含 38,035 个正文英文词形，其中 26,674 次直接匹配、6,686 次规则推断、4,675 次未匹配；另有 20 次重叠词组匹配。仓库只保存派生计数，不分发试卷或解析原文。该统计暂未接入应用或 V2 重要性公式。

复算方法：将 [语料仓库固定版本](https://github.com/LIziak112/structured-kaoyan-english/tree/ce0e9ac7c48e74738ffaeb04ff7033e69ea314c9) 放入本地 `sources/structured-kaoyan-english`，运行 `npm run data:exam1`。也可传入其他本地语料目录：`npm run data:exam1 -- /path/to/corpus`。脚本逐份验证文件内容的 Git blob SHA-1 后才统计，若来源版本或正文结构变化则停止。上游为非官方结构化数据，可能存在录入错漏。

## 排序的时间段验证

运行 `npm run eval:exam1` 可复算 [排序验证结果](../data/exam1-ranking-eval.json)，不需原始试卷。2010—2017 年为训练期，2018—2021 年为验证期；仅凭验证期选择算法，再用 2010—2021 年重建候选排名，以 2022—2025 年检验。词次与词条覆盖率的分母均为相应测试范围内命中词库的单词（排除多词短语以免重复计数），并非全部正文词形。分别统计全词群、排除 A1/A2（保留难度未知）和已知 B1 及以上词群，以及严格匹配和含推断两种口径。

验证期以非 A1/A2 词群的前 500、1000、2000 词的严格匹配词次与词条覆盖率平均值选取候选算法。最优候选为 50% 对数归一化词频（直接匹配 + 0.5 × 推断匹配）及 50% 加权跨年出现率（直接命中年份权重 1，仅推断命中年份权重 0.5）。验证期得分 69.66%；2022—2025 年非 A1/A2 词群前 1000 词的直接匹配词次/词条覆盖率为 77.98% / 60.64%。对应 V2 为 35.98% / 48.91%，混合词频为 78.04% / 62.23%。上游词频及 V2 可能使用测试年份信息，仅作回顾性参照；词库和 CEFR 也是回顾性定义。该实验衡量词汇覆盖，不衡量考试成绩或个体掌握程度，不据此替换 V2。

抽查 2010、2015、2020、2025 年的规则推断，计 1,737 次、789 种词形到词条组合。例如 according → accord 可能混淆固定搭配 according to 与动词 accord；没有词性和语义消歧时不应把推断次数等同于准确词元次数。未以测试年份的观察反向修改本次模型或统计。

### 应用内英语一词频

`npm run data:exam1:app` 将独立统计报告转换为离线应用资源 `app/data/exam1.js`，只包含词条、直接匹配次数、推断次数、出现年份数及估计名次。词库与今日新词均可切换英语一词频；未检出词排在有观察记录的词之后，并按原综合重要性排列。混合来源词频、综合重要性和复习调度不变。资源缺失或与词库 ID 不匹配时，禁用英语一排序并回退到综合重要性。演示词库不使用完整真题排名。
