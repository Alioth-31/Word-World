# 信息架构与教学呈现规范

## 内容归属

| 内容 | 位置 | 默认显示 |
|---|---|---|
| 今日任务及新词/复习数量 | 今日主任务卡 | 是 |
| 核心词已学数量 | 今日进度 | 是 |
| 本组词表 | 今日进度下方 | 否 |
| 词义、重点用法与例句 | 答案揭示阶段 | 是 |
| 记忆提示、更多义项、考研数据 | 答案内折叠区 | 否 |
| 熟词僻义筛选、排序 | 词库 | 入口可见 |
| 统计口径、来源 | 词条详情 | 否 |
| 学习记录与覆盖 | 学习记录 / 概览 | 是 |
| 7/30 日趋势 | 学习记录 / 学习趋势 | 按页签 |
| 延迟回忆、薄弱项、排程 | 学习记录 / 记忆与巩固 | 按页签 |
| Word FC 入口 | 今日 | 可选 |
| 比赛、赛季、俱乐部及阵容 | Word FC 弹层 | 分页、按需展开 |
| 学习设置与说明 | 我的 | 分组 |

## 教学决策

回忆阶段不提前显示答案、义项、例句或考频；核对阶段使用紧邻目标用法的搭配和例句。记忆评价直接在页底操作。原有复习调度、考试重要性、考频、个人薄弱项、专项插入机制保留；不改变数据意义，不把已学当成掌握。此处的分层是基于研究的设计决策，并非学习效果实证结论。
