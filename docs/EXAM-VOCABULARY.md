# 考研词汇内容与排序设计

每个词条展示两个独立证据维度：V2 综合重要性及英语一估计出现次数/复现年份。折叠说明记录原始排名、直接出现与词形推断、语料覆盖范围。原混合考试词频不替代英语一数据。

推荐队列先复习到期知识，再按每日预算和新词目标安排新词。新词分级不变，级内排序分数为 0.65×原排名归一值 + 0.35×(0.7×英语一估计排名归一值 + 0.3×未复现年份比例)，个人缺口最多扣 0.16。分数越低越优先；缺失统计按原排名处理，统计为零单独处理。重要性、纯英语一频率仍可独立排序。这是可解释的启发式，不是最优模型。

当前试点内容包括 36 个结构化词条与 41 个独立学习单位。

熟词僻义与搭配内容：采用词条级扩展数据，保留常见义、重点义、搭配、原创语境、译文、对比线索和来源说明。不凭单词出现次数推断某个义项的考频。不将所有多义词都自动归为考研高频僻义。专项单位沿用稳定的独立记忆 ID；仅在已学或自认熟悉词中安排新专项，个人诊断部分认识或最近模糊、遗忘者优先。每组最多一个新专项；到期积压可处理且预算允许时为其预留时间和位置。同一个词最近24小时有专项练习则暂缓新增其他用法，到期项目不受影响。优先个人诊断缺口、用法覆盖较少的词、非拼写练习和考试价值。`account-proportion`、`subject-participant`、`fine-distinction` 与原有 ID 分离。词条详情提供可折叠的额外用法。

后续优先导入已有结构化开放词典的义项及搭配，再从有授权的真题语料逐个对齐真实义项证据；未经校核的自动匹配不进入“真题义项”标签。保持词书与个人记忆分离。
