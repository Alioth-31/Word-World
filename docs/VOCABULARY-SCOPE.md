# 词汇短课与后台策略

核心路径：启动今日学习 → 复习到期词 / 认识少量新词 → 核对词义和用法 → 失败时组末重新提取 → 保存记忆记录 → 下一组。默认每组最多 8 个初始任务、最多 5 个新词；错误词最多增加一次组内修复，不增加每日新词或 FSRS 复习次数。每个组内新用法任务最多一个，且仅限已经学习的单词。旧用法记忆到期后随普通词汇进入统一队列。例句在核对时显示，额外义项按需展开；已有部分义项或反复遗忘时自动打开扩展释义。题库不足时不生成任意干扰项。

复习优先：全局到期队列按时间排序。真实用时估计由既有稳健成本估计器提供；剩余预算与每日新词目标限制新任务。预算不足仍可继续到期复习。没有保留给整篇材料、考试题型或额外专项课的固定时间。复习与新词统一短课，单项记忆由既有 FSRS 执行，组内修复只是教学反馈。

内容与能力：目标优先级采用既有个人诊断、重要性与英语一词频；已有单词及其语境练习分别保存，前者不因后者答对被更新。首次错误、延迟回忆和近变式作答保留不同证据。缺少高质量语境时直接学习释义，不强制生成练习。个人用时与延迟错误证据用于选择任务与扩展解释，属于可解释启发式，未经过学习效果对照实验。

学习者侧：今日推荐、今日新词进度、待复习数、词库搜索、个人设置；算法与策略不作为独立页面。保持简单的三步交互（回忆、核对、评价），错误时增加必要修复。自评不等于客观掌握，现有少量用法题仅作学习活动，不作综合能力评分。
